Publishing your changes to GitHub

Once you've finished editing, follow these steps to update the live copy on GitHub. You don't need any special software — this is all done in your browser.

  1. Make sure you started with the current file. This tool has no data of its own — you should have already uploaded the current map-data.js (ideally freshly downloaded from GitHub) before making your edits, so nothing gets overwritten by accident.
  2. Download the file. Click the "⬇ Download updated map-data.js" button above. It will save a file called map-data.js to your computer's Downloads folder.
  3. Check the filename. Look in your Downloads folder. If your browser saved it as map-data (1).js or similar, rename it back to exactly map-data.js — this matters, as it must match the existing file exactly.
  4. Open the GitHub repository in your browser and sign in if needed.
  5. Find the existing map-data.js file in the repository (you may need to open a folder first, depending on where it lives).
  6. Click into the file, then click the pencil (✏️) "Edit" icon — or, from the folder listing, click Add file → Upload files and drag your downloaded map-data.js into the box. GitHub will recognise it has the same name and offer to replace it.
  7. Scroll to the bottom of the page. Under "Commit changes", type a short note describing what you changed, e.g. "Add electoral roll entries for Barry Street, 1928".
  8. Make sure "Commit directly to the main branch" is selected, then click Commit changes.
That's it — your changes are now live in the repository. If the map is hosted with GitHub Pages, it can take a minute or two to update after you commit.

If you're ever unsure whether your edits "took", you can come back to this tool, click "Load a different file…" and open the file straight from GitHub (use the "Raw" download) to check it matches what you expect.
